# NVCI 新手任务向导：采集归档阶段产品需求

## 1. 产品定位

新手任务向导是 NVCI 的**资料采集、分析整理与归档入口**。它帮助产品经理以厂商、产品线、系列、资料类型、执行时间和归档字段目录定义一张可追踪任务卡，并把任务交给 NAS 内的确定性采集器执行。

本阶段不做跨厂商竞争对比、型号映射、评分、排名、采购建议或“谁优于谁”的结论。任何竞争分析只能在后续阶段，基于已完成的可审计资料资产和经批准的字段事实另行发起。

## 2. 用户与价值

| 用户 | 需要解决的问题 | 向导交付 |
|---|---|---|
| 产品经理 | 快速建立可复用的产品资料底座，而不是临时搜索结果 | 任务卡、产品/型号清单、产品页 URL、PDF URL、归档字段目录 |
| 资料管理员 | 控制来源、文件变更和目录质量 | 已批准来源、SHA-256、manifest、不可变快照、五列表 |
| 研发/售前 | 获得可复核的官方资料入口 | PDF、资料路径、证据规则、未披露/待复核标记 |

## 3. 六步流程

| 步骤 | 用户选择 | 系统门禁与输出 |
|---|---|---|
| 1. 归档目标 | 任务名称、资料范围与归档目的 | 禁止空泛目标；提示本阶段不生成竞争结论 |
| 2. 厂商范围 | 单品牌或多品牌并行 | 多品牌只并行采集独立资产，不合并为竞争矩阵 |
| 3. 产品线范围 | 已登记的产品线、子系列、来源配置 | 仅已批准且已启用的来源可自动执行 |
| 4. 执行方式 | 立即、一次预约、每日、每周 | 由 NAS 后台 Worker 持续执行；来源未批准时阻塞 |
| 5. 归档字段目录 | 选择产品域字段模板与关键字段 | 创建待批准字段目录，不自动抽取和推断值 |
| 6. 确认提交 | 检查数量、来源、计划、输出 | 创建采集归档任务卡、研究任务记录与字段目录审批项 |

## 4. 采集模式

| 模式代码 | 用户名称 | 约束 | 结果 |
|---|---|---|---|
| `single_vendor_archive` | 单品牌采集归档 | 恰好一个厂商 | 单品牌产品/系列/型号、官方资料链与归档字段目录 |
| `multi_vendor_archive` | 多品牌并行采集归档 | 至少两个厂商；每厂商至少一个来源配置 | 分品牌独立资料资产，不创建候选对标关系 |
| `collection_update` | 资料增量更新 | 至少一个厂商 | 复用 HTTP 元数据与 SHA-256，仅处理新增、变化和失效资料 |

旧任务中的 `vertical` 和 `horizontal` 模式在读取时分别兼容为单品牌采集归档和多品牌并行采集归档；不再向新任务暴露这两个研究模式。

## 5. 执行与资产契约

采集器是确定性 Node.js 脚本，只消费已批准来源配置；不依赖大模型、浏览器会话或用户在线状态。每个资料条目必须经过官方 HTTPS 域名、受控重定向、HTTP 元数据、PDF 签名、基础可读性、系列/型号匹配和 SHA-256 门禁。

一次运行至少产生不可变快照、PDF、`document_manifest.csv`、`path_health_log.csv`、`change_log.csv`、五列表、`update_summary.csv`、`run.json` 和 `manifest.json`。产品页 URL、资料页/PDF URL、型号/系列与证据规则保留在来源配置与任务详情中。

## 6. 状态机

| 状态 | 含义 | 可行动作 |
|---|---|---|
| `draft` | 草稿尚未提交 | 编辑或删除 |
| `blocked` | 来源未批准、已禁用或计划到期时门禁不通过 | 修复来源并重试 |
| `scheduled` | 等待一次预约、每日或每周触发 | 立即执行、暂停或修改计划 |
| `queued` | 已进入 Worker 队列 | 查看队列和来源范围 |
| `collecting` | 至少一项来源正在采集 | 查看运行日志 |
| `archive_ready` | PDF 与资料索引已完成，等待整理或字段目录批准 | 查看资产、批准字段目录、进入资料整理 |
| `review_required` | 下载失败、资料变化或证据门禁异常 | 查看错误与人工复核 |
| `paused` | 周期计划已暂停 | 恢复或归档 |

## 7. 明确非目标

本版本不调用 AI 模型；不抓取未登记 URL；不绕过登录、验证码或访问控制；不把“未披露”写成“不支持”；不进行竞争对比、产品分档、型号映射、评分或采购建议。

## 8. 验收标准

1. 用户可按单品牌、多品牌并行或资料增量三种方式创建任务，并选择一个或多个厂商与产品线来源。
2. 支持立即、一次预约、每日和每周执行，且任务由 NAS Worker 在浏览器关闭后继续运行。
3. 任务详情可显示型号/系列、产品页 URL、PDF URL、证据规则、资料数、执行请求、快照与归档状态。
4. 未批准来源、无效时间和空字段目录必须被明确阻止。
5. 采集结果必须生成标准化可审计资产；失败必须保留错误码和原始 URL。
6. 新手向导不显示或写入竞争关系、型号映射、评分和对比结论。
